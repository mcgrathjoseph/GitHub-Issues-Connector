
Summary of Key Points
=====================
- Root cause of runtime failure was eager construction of ClientSecretCredential during local development.
- The tenantId error was NOT related to tsconfig.json, typeRoots, UNC paths, or missing package.json files.
- Fix was to fully adopt the PnP (OAuth-off-in-dev) pattern by guarding Azure Identity usage.
- graphClient.ts was the final blocking file; adding a Joe-style dev guard resolved the tenantId crash.
- Azure Functions now start cleanly in local/dev mode using Tools_Joe_3 func.exe.
- A dev-only ping function (pingJoe) confirms job discovery and HTTP trigger registration.

Full Context and Resolution
===========================
Over the course of this session, we debugged why the GitHub Issues Connector Azure Functions app failed to start locally with the error:

  ClientSecretCredential: tenantId is a required parameter

Key conclusions:
- Azure Functions was crashing during startup, before function registration.
- This was due to unconditional creation of ClientSecretCredential.
- config.ts validation guards alone were insufficient because @azure/identity was invoked earlier in graphClient.ts.

The definitive fix was applied in graphClient.ts by introducing a Joe-style development guard:

  const isDevelopment_Joe =
    process.env.AZURE_FUNCTIONS_ENVIRONMENT === "Development" ||
    process.env.NO_AUTH_LOCAL === "true";

and preventing ClientSecretCredential from being constructed in dev mode.

Once this guard was applied, the tenantId crash disappeared and Azure Functions successfully launched.

Dev-Only Ping Function Added
============================
To confirm end-to-end success (JoeDebug2 passed), a minimal dev-only HTTP function was added.

File Location:
  src/functions/pingJoe.ts

Complete Source:

------------------------------------------------------------
import { app, HttpRequest, HttpResponseInit, InvocationContext } from "@azure/functions";

// Joe: simple dev-only ping to verify function registration
export async function pingJoe(
  req: HttpRequest,
  context: InvocationContext
): Promise<HttpResponseInit> {

  context.log("Joe ping function invoked");

  return {
    status: 200,
    jsonBody: {
      message: "✅ Joe ping OK",
      environment: process.env.AZURE_FUNCTIONS_ENVIRONMENT,
      timestamp: new Date().toISOString(),
    },
  };
}

// Joe: register ONLY in Development / local mode
if (
  process.env.AZURE_FUNCTIONS_ENVIRONMENT === "Development" ||
  process.env.NO_AUTH_LOCAL === "true"
) {
  app.http("pingJoe", {
    methods: ["GET"],
    authLevel: "anonymous",
    handler: pingJoe,
  });
}
------------------------------------------------------------
