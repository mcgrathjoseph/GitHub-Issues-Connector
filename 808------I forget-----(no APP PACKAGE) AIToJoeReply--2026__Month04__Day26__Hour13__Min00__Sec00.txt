------------------------------------------------------------
Why Each of Those Files Is Wrong
------------------------------------------------------------

1) node_modules/**/manifest.json
--------------------------------
- These belong to third-party libraries or build tooling.
- They are not Teams app manifests.
- Selecting one would create an invalid app package.

2) Tools_Joe_3/.../_manifest/manifest.json
-------------------------------------------
- This is a PowerShell worker runtime manifest.
- It tells Azure Functions how to host PowerShell.
- It has nothing to do with Teams or Copilot apps.

3) azure-functions-core-tools/bin/workers/.../_manifest/manifest.json
---------------------------------------------------------------------
- This is an Azure Functions runtime manifest shipped by Microsoft.
- It describes how language workers behave.
- It is infrastructure-level metadata, not an app definition.

4) azure-functions-core-tools/bin/in-proc8/workers/.../_manifest/manifest.json
------------------------------------------------------------------------------
- Same as above, but for in-proc hosting.
- Entirely unrelated to Microsoft 365 app packaging.

Architectural Truth (This Ends the Confusion)
